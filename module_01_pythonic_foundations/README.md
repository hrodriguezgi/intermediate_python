# Module 1 · Pythonic Foundations

Este módulo refuerza la forma idiomática de trabajar con variables, colecciones y datos de texto en Python.

## Lecciones

- `01_data_model_and_unpacking.py`: modelo de datos, mutabilidad, asignación múltiple y desempaque.
- `02_strings_collections_and_dates.py`: formateo, colecciones útiles y fechas con `datetime`.

## Ejercicios

### Fundamentos
- `exercises/lesson_01_student_snapshot/`: Desempaque de tuplas y agregación de datos
- `exercises/lesson_02_release_agenda/`: Conversión de fechas y cálculo de offsets con `timedelta`

### Datos Mutables & Estructuras Complejas
- `exercises/lesson_03_student_records_backup/`: Copias profundas vs superficiales — evitar el trap de referencias compartidas con datos anidados
- `exercises/lesson_04_data_normalization/`: Normalizar datos desordenados con `split()`, `strip()`, `Counter` — patrón típico de ETL
- `exercises/lesson_05_parallel_schedules/`: Emparejar datos con `zip()` y `enumerate()` sin índices manuales
